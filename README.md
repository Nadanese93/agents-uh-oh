One word an agent says when it realises it is lost: **Looping**.

Run `python3 main.py` and it writes exactly that one word — no trailing
newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if
unset). 2 USDC prize, top 10.
